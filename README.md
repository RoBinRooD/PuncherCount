# PuncherCount 🥊

เว็บแอปนับหมัดชกกระสอบด้วยกล้องมือถือ (computer vision บนเบราว์เซอร์) แยก **หมัดซ้าย/ขวา** และ **ประเภทหมัด**
(แย็บ, หมัดตรง, ฮุก, อัปเปอร์คัต + หมัดเข้าลำตัว) พร้อมจับเวลาเป็นยก และแดชบอร์ดสรุปผลแต่ละเซต

ทำงานบนเครื่องผู้ใช้ทั้งหมด ไม่มีเซิร์ฟเวอร์ — โฮสต์บน GitHub Pages ได้ และข้อมูลเก็บใน IndexedDB ของเบราว์เซอร์

## วิธีใช้
1. วางมือถือ **ด้านข้างกระสอบ** ให้เห็นผู้ชกด้านข้างตั้งแต่ศีรษะถึงสะโพก
2. แท็บ **ตั้งค่า** → เลือก Orthodox/Southpaw, จำนวนยก, เวลาชก/พัก
3. แท็บ **ฝึกซ้อม** → กด "เปิดกล้อง / ทดสอบท่า" แล้วลองชก จะมีป้ายบอกมือและประเภทหมัด (โหมดทดสอบไม่บันทึก)
   - ถ้าแขนสีฟ้า (ซ้าย) ไปอยู่ที่มือขวาจริง ให้เปิด "สลับซ้าย/ขวา"
   - ถ้านับขาด/เกิน ปรับ "ความเร็วขั้นต่ำ" และ "ระยะยื่นขั้นต่ำ" (เปิด "ข้อมูลดีบัก" ช่วยดูค่าได้)
4. กด **เริ่ม** — นับถอยหลัง → ชก → พัก ตามจำนวนยก จบแล้วพาไปหน้าสรุปเซต
5. แท็บ **แดชบอร์ด** ดูประวัติ, ส่งออก JSON (สำรอง) / CSV, นำเข้า JSON

## Tech stack

| Test | Vitest |
| Deploy | GitHub Actions → GitHub Pages |

## หลักการตรวจจับ (`src/lib/detector.ts`)
- ตำแหน่งข้อมือคิดเทียบกับไหล่ และหารด้วยความยาวลำตัว → ไม่ขึ้นกับระยะห่างจากกล้องหรือการขยับตัว
- ข้อมือเร็วเกินเกณฑ์ = เริ่มหมัด, หยุด/เริ่มดึงกลับ = จบหมัด แล้วจำแนกจากเวกเตอร์การเคลื่อนที่:
  - ขึ้นเป็นหลัก → **อัปเปอร์คัต**
  - ไปข้างหน้า + ศอกยังงอตอนสุดหมัด → **ฮุก**
  - ไปข้างหน้า + แขนเหยียด → **หมัดตรง** (มือหน้า = แย็บ, มือหลัง = ครอส)
  - ข้อมือจบต่ำกว่าไหล่มาก → ติดป้าย **ลำตัว**
- ทิศ "ข้างหน้า" หาอัตโนมัติจากตำแหน่งจมูกเทียบไหล่ (หันซ้ายหรือขวาของภาพก็ได้)
- การจำแนกประเภทเป็น heuristic ควรปรับเกณฑ์ในหน้า ตั้งค่า ให้เข้ากับมุมกล้องจริง

## พัฒนา
```bash
npm install
npm run dev      # เปิดจากมือถือในวง LAN ได้ (กล้องต้องใช้ HTTPS หรือ localhost)
npm test
npm run build
```
`predev`/`prebuild` จะคัดลอก MediaPipe WASM จาก `node_modules` และดาวน์โหลดโมเดลมาไว้ที่ `public/mediapipe/` (ไม่ commit)

## Deploy บน GitHub Pages
1. Settings → Pages → Source: **GitHub Actions**
2. Push/merge เข้า `main` → workflow `.github/workflows/deploy.yml` จะ test, build และ deploy
3. เปิด `https://<user>.github.io/<repo>/` บนมือถือ แล้ว "เพิ่มลงหน้าจอโฮม" เพื่อใช้แบบแอป
