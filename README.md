# PuncherCount 🥊

เว็บแอปนับหมัดชกกระสอบด้วยกล้องมือถือ (computer vision บนเบราว์เซอร์) แยก **หมัดซ้าย/ขวา** และ **ประเภทหมัด**
(แย็บ, หมัดตรง, ฮุก, อัปเปอร์คัต + หมัดเข้าลำตัว) พร้อมจับเวลาเป็นยก และแดชบอร์ดสรุปผลแต่ละเซต

ทำงานบนเครื่องผู้ใช้ทั้งหมด ไม่มีเซิร์ฟเวอร์ — โฮสต์บน GitHub Pages ได้ และข้อมูลเก็บใน IndexedDB ของเบราว์เซอร์

## วิธีใช้
1. วางมือถือ **ด้านข้างกระสอบ** ให้เห็นผู้ชกด้านข้างตั้งแต่ศีรษะถึงสะโพก
2. แท็บ **ตั้งค่า** → เลือก Orthodox/Southpaw, จำนวนยก, เวลาชก/พัก
3. แท็บ **ฝึกซ้อม** → กด "เปิดกล้อง / ทดสอบท่า" แล้วลองชก จะมีป้ายบอกมือและประเภทหมัด (โหมดทดสอบไม่บันทึก)
   - ถ้าแขนสีฟ้า (ซ้าย) ไปอยู่ที่มือขวาจริง ให้เปิด "สลับซ้าย/ขวา"
   - ถ้านับขาด/เกิน ปรับ "ความเร็วขั้นต่ำ" และ "ระยะยื่นขั้นต่ำ" (เปิด "ข้อมูลดีบัก" ช่วยดูค่าได้)
4. กด **เริ่ม** — นับถอยหลัง → ชก → พัก ตามจำนวนยก จบแล้วพาไปหน้าสรุปเซต
5. (แนะนำ) แท็บ **สอนท่า** → อัปโหลดคลิปที่ถ่ายจากมุมเดียวกัน 1 คลิปต่อ 1 ท่า (เช่น แย็บซ้าย 10 ครั้ง) แล้วติดป้าย
   แอปจะเรียนรู้ประเภทหมัดจากคลิป และถ้าใส่จำนวนหมัด จะปรับความไวการนับให้ด้วย
6. แท็บ **แดชบอร์ด** ดูประวัติ, ส่งออก JSON (สำรอง) / CSV, นำเข้า JSON

## หลักการตรวจจับ (`src/lib/detector.ts`)
- ตำแหน่งข้อมือคิดเทียบกับไหล่ และหารด้วยความยาวลำตัว → ไม่ขึ้นกับระยะห่างจากกล้องหรือการขยับตัว
- ข้อมือเร็วเกินเกณฑ์ = เริ่มหมัด, หยุด/เริ่มดึงกลับ = จบหมัด แล้วจำแนกจากเวกเตอร์การเคลื่อนที่:
  - ขึ้นเป็นหลัก → **อัปเปอร์คัต**
  - ไปข้างหน้า + ศอกยังงอตอนสุดหมัด → **ฮุก**
  - ไปข้างหน้า + แขนเหยียด → **หมัดตรง** (มือหน้า = แย็บ, มือหลัง = ครอส)
  - ข้อมือจบต่ำกว่าไหล่มาก → ติดป้าย **ลำตัว**
- ทิศ "ข้างหน้า" หาอัตโนมัติจากตำแหน่งจมูกเทียบไหล่ (หันซ้ายหรือขวาของภาพก็ได้)
- การจำแนกประเภทเป็น heuristic ควรปรับเกณฑ์ในหน้า ตั้งค่า ให้เข้ากับมุมกล้องจริง หรือสอนท่าจากคลิป (ด้านล่าง)

## สอนท่าจากคลิป (`src/lib/trainer.ts`, `src/pages/Teach.tsx`)
- คลิปถูกวิเคราะห์ในเบราว์เซอร์ทีละเฟรม (30 fps) เก็บเฉพาะ landmark ลง IndexedDB (ตาราง `clips`) ไม่เก็บวิดีโอ
- ทุกการเคลื่อนไหวออกหมัดของมือที่ติดป้าย = ตัวอย่างของท่านั้น, การขยับของมืออีกข้าง = ตัวอย่าง "ไม่ใช่หมัด"
- จำแนกด้วย k-nearest-neighbours บน feature การเคลื่อนที่ (ระยะ/ทิศ/มุมศอก/ระยะเวลา) — ท่าที่ยังไม่ได้สอนหรือหมัดที่ไม่เหมือนตัวอย่างใดเลยจะใช้ heuristic แทน
- หน้าสอนท่าแสดงความแม่นยำแบบ leave-one-clip-out เทียบกับ heuristic และปรับ "ความเร็ว/ระยะยื่นขั้นต่ำ" ให้นับตรงกับจำนวนหมัดที่ใส่ไว้

## Google Drive

เก็บข้อมูลทั้งหมดไว้ในโฟลเดอร์ **PuncherCount** บน Google Drive ของคุณ (ใช้หลายเครื่องได้ และข้อมูลไม่หายถ้าล้างเบราว์เซอร์)
- `index.json` — ประวัติการซ้อมทุกเซต และรายการสิ่งที่ถูกลบ
- `clip-<เวลา>.json` — คลิปสอนท่า (ป้าย, จำนวนหมัด, ท่าทางที่ถอดจากวิดีโอ)
- วิดีโอต้นฉบับของคลิปที่เพิ่มตอนเชื่อม Drive อยู่ (ชื่อไฟล์บอกป้ายและเวลา)

แอปซิงก์อัตโนมัติหลังมีการเปลี่ยนแปลง ใช้ scope `drive.file` จึงเห็นเฉพาะไฟล์ที่แอปสร้างเอง
token ของ Google หมดอายุทุก ~1 ชั่วโมง ถ้าขึ้น "แตะเพื่อเข้าสู่ระบบและซิงก์" ให้แตะปุ่มนั้นอีกครั้ง

### สร้าง OAuth Client ID (ทำครั้งเดียว)
1. เปิด [Google Cloud Console](https://console.cloud.google.com/) → สร้างโปรเจกต์ใหม่ (ชื่ออะไรก็ได้ เช่น PuncherCount)
2. **APIs & Services → Library** → ค้นหา **Google Drive API** → Enable
3. **Google Auth Platform** (หรือ OAuth consent screen) → Get started
   - App name: PuncherCount, อีเมลของคุณ, Audience: **External**
   - ที่ **Audience → Test users** เพิ่มอีเมล Google ที่จะใช้ล็อกอิน
4. **Clients → Create client** → Application type: **Web application**
   - Authorized JavaScript origins: `https://robinrood.github.io` (เพิ่ม `http://localhost:5173` ถ้าจะทดสอบตอน dev)
   - ไม่ต้องใส่ Redirect URI
5. คัดลอก **Client ID** (ลงท้ายด้วย `.apps.googleusercontent.com`) → ในแอป แท็บ **ตั้งค่า → Google Drive** วาง แล้วกด **เชื่อมต่อ Google Drive**
   - ตอนล็อกอินครั้งแรก Google จะเตือนว่าแอปยังไม่ผ่านการตรวจสอบ ให้กด Continue (เป็นแอปของคุณเอง)

Client ID ไม่ใช่ความลับ จะฝังไว้ในแอปเลยก็ได้: GitHub repo → Settings → Secrets and variables → Actions → **Variables** → เพิ่ม `GOOGLE_CLIENT_ID` แล้ว deploy ใหม่ (ไม่ต้องวางในหน้าตั้งค่าอีก)

## พัฒนา
```bash
npm install
npm run dev      # เปิดจากมือถือในวง LAN ได้ (กล้องต้องใช้ HTTPS หรือ localhost)
npm test
npm run build
```
`predev`/`prebuild` จะคัดลอก MediaPipe WASM จาก `node_modules` และดาวน์โหลดโมเดลมาไว้ที่ `public/mediapipe/` (ไม่ commit)

## Deploy บน GitHub Pages
1. Settings → Pages → Source: **GitHub Actions**
2. Push/merge เข้า `main` → workflow `.github/workflows/deploy.yml` จะ test, build และ deploy
3. เปิด `https://<user>.github.io/<repo>/` บนมือถือ แล้ว "เพิ่มลงหน้าจอโฮม" เพื่อใช้แบบแอป
